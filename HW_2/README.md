# HW_2 «Кибер-Зоопарк 2077»

Кулин Егор Алексеевич

## Инструкция по запуску

1.  Установите зависимости: `npm install`
2.  Запустите сервер для разработки: `npm run dev`

Приложение будет доступно по адресу `http://localhost:5173`.

## Улучшения на 9-10 баллов

### 1. Сохранение состояния
Реализовано сохранение состояния питомцев и лога событий в `localStorage`. При перезагрузке страницы энергия, настроение и уровень питомцев не сбрасываются. История событий также сохраняется между сессиями.

### 2. Адаптивный дизайн
Приложение полностью адаптировано для мобильных устройств. На экранах шириной менее 900px боковая панель лога событий скрывается, чтобы не занимать место. Сетка карточек автоматически перестраивается в одну колонку на узких экранах. Размеры шрифтов и отступы оптимизированы для мобильных устройств. Также использованы медиа-запросы Material UI (`sx={{ display: { xs: 'none', md: 'block' } }}`).
