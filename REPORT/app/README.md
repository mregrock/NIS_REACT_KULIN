# CineSwipe — Tinder для фильмов

Приложение для быстрого выбора фильмов в стиле Tinder. Свайпай карточки вправо — если фильм нравится, влево — если нет. Тапни на карточку, чтобы узнать подробности.

## Технологии

| Технология | Версия | Назначение |
|---|---|---|
| React | 18 | UI-фреймворк, компонентный подход |
| Vite | 5 | Сборщик и dev-server |
| TypeScript | 5 | Статическая типизация |
| Tailwind CSS | 3 | Утилитарные стили, тёмная тема |
| Framer Motion | 11 | Анимации карточек (drag, swipe, AnimatePresence) |
| Zustand | 4 | Глобальное состояние (очередь, лайки, история) |
| Axios | 1 | HTTP-запросы к ПоискКино API |

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на [http://localhost:5173](http://localhost:5173).

> API-ключ [poiskkino.dev](https://poiskkino.dev/) уже встроен в код — регистрация не нужна.

### Сборка для продакшена

```bash
npm run build
npm run preview
```

## Возможности

- Drag-to-swipe с анимацией поворота и цветным оверлеем «НРАВИТСЯ / ПРОПУСК»
- Тап на карточку — детальная информация: описание, рейтинги IMDb и КП, длительность, страны
- Стек из 3 карточек с анимацией глубины
- Фильтр по жанрам (15 жанров)
- Рекомендательная система: после нескольких лайков API подбирает фильмы похожих жанров
- Список понравившихся с возможностью просмотра деталей и удаления
- История из 200 просмотренных фильмов — повторы не появляются
- Лайки и предпочтения сохраняются в localStorage
