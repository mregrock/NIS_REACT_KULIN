# REPORT — CineSwipe: Tinder для фильмов

## Суть приложения

**CineSwipe** — это веб-приложение, которое позволяет быстро и весело выбирать фильмы для просмотра. Принцип работы заимствован у Tinder: пользователю показывается стек карточек с постерами фильмов из базы TMDB. Карточку можно перетащить вправо (нравится) или влево (не интересно), либо воспользоваться кнопками и клавишами со стрелками. Понравившиеся фильмы сохраняются в боковой панели и не теряются при перезагрузке страницы (Zustand persist). Жанровый фильтр позволяет сузить выборку под настроение.

Ключевые возможности:
- Drag-to-swipe с визуальной обратной связью (поворот карточки, цветной оверлей)
- Стек из 3 карточек с анимацией глубины
- Простая система рекомендаций на основе жанровых весов: свайп вправо увеличивает приоритет жанров фильма (+2), свайп влево — понижает (-1). Очередь пересортировывается после каждого свайпа
- Фильтр по жанрам
- Список понравившихся с возможностью удаления
- Клавиатурные шорткаты (← →)
- Лайкнутые фильмы и жанровые предпочтения сохраняются в localStorage

## Технологии

### React 18

React — декларативная JavaScript-библиотека для построения пользовательских интерфейсов на основе компонентов. В проекте используется для разбиения UI на независимые переиспользуемые части: `MovieCard`, `CardStack`, `ActionButtons`, `LikedMovies`. React 18 принёс Concurrent Features и улучшил работу `useEffect` в StrictMode.

**Альтернативы:** Vue 3 (опциональный API, меньше экосистема), Svelte (компилируемый, нет Virtual DOM — быстрее, но менее зрелая экосистема), Angular (тяжеловесный, избыточен для небольшого SPA). React выбран как наиболее распространённый и с богатейшей экосистемой.

---

### Vite

Vite — это современный инструмент сборки, использующий нативные ES Modules в режиме разработки. Это даёт мгновенный холодный старт и быструю горячую замену модулей (HMR). Production-сборка основана на Rollup.

**Альтернативы:** Create React App (устарел, медленный Webpack), Webpack (гибкий, но сложная конфигурация), Parcel (zero-config, но менее популярен). Vite выбран за скорость и простоту настройки.

---

### Tailwind CSS

Tailwind — utility-first CSS фреймворк. Вместо написания кастомных классов в CSS-файлах стили задаются прямо в JSX через классы-утилиты (`flex`, `gap-4`, `rounded-3xl`). Это ускоряет разработку и исключает проблему конфликта имён. В проекте используется для вёрстки карточек, хедера, панели лайков и тёмной темы.

**Альтернативы:** CSS Modules (изоляция, но больше файлов), styled-components (CSS-in-JS, runtime overhead), MUI / Ant Design (готовые компоненты, но слабая кастомизация). Tailwind выбран за гибкость и производительность.

---

### Framer Motion

Framer Motion — библиотека анимаций для React с декларативным API. В проекте применяется для:
- `useMotionValue` + `useTransform` — отслеживание позиции при drag и вычисление поворота/opacity оверлея
- `drag` prop — нативный drag с инерцией
- `AnimatePresence` — анимация исчезновения карточки из DOM
- `motion.div` с `animate` — стековая анимация (scale, y)

**Альтернативы:** React Spring (физические пружины, более низкоуровневый), GSAP (мощный, но не React-специфичный), CSS transitions (нет поддержки gesture-based анимаций). Framer Motion выбран за лучшую интеграцию с React и удобный drag API.

---

### Zustand

Zustand — минималистичная библиотека управления состоянием для React. Хранит состояние вне компонентов и не требует Provider-обёрток. В проекте в едином сторе хранятся очередь фильмов, список лайков, жанры, страница пагинации и состояние загрузки. Middleware `persist` автоматически сохраняет лайки в localStorage.

**Альтернативы:** Redux Toolkit (много boilerplate, избыточен), Jotai / Recoil (атомарная модель, хорошо для сложных зависимостей), Context API (ре-рендеры при любом изменении). Zustand выбран за простоту и минимальный размер бандла (< 1 KB).

---

### Axios

Axios — promise-based HTTP-клиент с поддержкой интерсепторов, базового URL и автоматической сериализацией JSON. В проекте создаётся инстанс с `baseURL` и глобальными параметрами (`api_key`, `language`), что избавляет от повторения конфигурации в каждом запросе. Используется для запросов к TMDB API: список фильмов (`/discover/movie`) и жанры (`/genre/movie/list`).

**Альтернативы:** Fetch API (нативный, нет интерсепторов, нет отмены запросов "из коробки"), SWR / React Query (хуки для кэширования, но избыточны для данного проекта). Axios выбран за удобный API и привычность в React-проектах.

---

## Заключение

В процессе работы над CineSwipe удалось применить весь стек современных инструментов фронтенд-разработки. Наиболее интересной частью оказалась реализация drag-анимации через Framer Motion: `useMotionValue` даёт прямой доступ к текущему значению без ре-рендеров, а `useTransform` позволяет реактивно вычислять производные значения — это элегантное решение.

Zustand приятно удивил лаконичностью: весь стор уместился в один файл без action-creators и редюсеров. Tailwind ускорил вёрстку в разы, хотя длинные строки классов поначалу кажутся неудобными.

Главный вывод: Vite + React + Tailwind + Zustand — это очень продуктивный стек для небольших SPA. Каждый инструмент делает ровно то, что нужно, без лишней сложности.
